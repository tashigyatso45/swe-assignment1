APPLICATION NAME: MY TASK LIST 

DESCRIPTION: 
I created this application to keep track of your tasks. There a form that lets you submit multiple tasks. After creating the task you can mark whether its done or not with a check box. If it's completed and you click the check box it changes into a different color to show that its complete. You can also delete a task after its done. 


HOW TO RUN IT 

Simply clone this repository and run the html file in the browswer. Make sure to have all of the files in one directory. 

Incomplete features: 

-  you can edit the tasks after submission
- the task are ordered based on timing of submission rather than priority.
